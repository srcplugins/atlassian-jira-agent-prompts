# Security

## Reporting a vulnerability

Report security problems privately, never in a public issue:

- **GitHub:** choose **Report a vulnerability** on this repository's **Security** tab.
- **Email:** support@srcplugins.com.

Say which app and version you use, what you found and how to reproduce it. Never send passwords, API tokens or customer data. Response times are on the [Service Level Agreement](https://srcplugins.com/sla/).

## Supported versions

Fixes are released as a new version of the latest release. Installed apps update automatically within the same major version.

## Contributions

Bug reports and feature requests are welcome as issues. Pull requests aren't accepted.
